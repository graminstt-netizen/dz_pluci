2) Структура динамический массив
Нужно реализовать динамический массив ( только с помощью malloc, free и realloc ) , нельзя использовать std::vector.
Массив должен:
1. Иметь конструктор по умолчанию, который создаёт пустой динамический массив.
2. Иметь конструктор из 1 аргумента типа int или size_t, создавая пустой массив с заранее преаллоцированным размером
3. Иметь перегрузку оператора operator[] для получения элемента по индексу
4. Иметь функцию Add для добавления элемента в конец массива.

При наполнении массива - перевыделять память на +10 элементов.
